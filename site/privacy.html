Confidentialité

Cette page décrit le principe général du site public Vanelle. La documentation spécifique aux versions du logiciel doit être consultée dans le dépôt et les documents associés.

Site public

Le site statique est hébergé via GitHub Pages. Les téléchargements sont distribués depuis GitHub Releases.

Application locale

Vanelle est conçue avec une architecture local-first. Les modèles et données utilisés pour les opérations locales restent sur la machine, sous réserve des fonctionnalités externes que l'utilisateur choisit explicitement d'utiliser.

Versions et téléchargements

Le site récupère publiquement la liste des releases GitHub pour afficher les versions et leurs fichiers.
